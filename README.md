# 🚀 Tracklify

Tracklify es una aplicación de escritorio desarrollada en Java orientada a la gestión de tareas y hábitos personales mediante un sistema inteligente de seguimiento y recordatorios.

## 📌 Descripción

El objetivo de Tracklify es ayudar a los usuarios a mejorar su productividad y mantener hábitos a largo plazo. A diferencia de las aplicaciones tradicionales de listas de tareas, Tracklify incorpora funcionalidades avanzadas como:

- Seguimiento de hábitos recurrentes
- Sistema de recordatorios inteligentes
- Registro de progreso
- Generación de informes
- Automatización de flujos de trabajo

---

## 🎯 Características principales

### 👤 Gestión de usuarios
- Registro e inicio de sesión
- Sistema de roles (Administrador / Usuario)

### ✅ Gestión de tareas y hábitos
- Crear, editar y eliminar tareas
- Configurar frecuencia (diaria, semanal, mensual)
- Activar o desactivar tareas
- Seguimiento de cumplimiento

### 🔔 Notificaciones
- Recordatorios automáticos
- Confirmación de tareas realizadas

### 🤖 Automatización
- Integración con n8n
- Ejecución de acciones automáticas según condiciones

### 📊 Informes y estadísticas
- Historial de hábitos
- Estadísticas de cumplimiento
- Evolución del progreso

---

## 🛠 Tecnologías utilizadas

- **Lenguaje:** Java  
- **Interfaz gráfica:** JavaFX  
- **Base de datos:** MySQL  
- **Gestión de dependencias:** Maven  
- **IDE:** Apache NetBeans  
- **Automatización:** n8n  
- **Reportes:** JasperReports  
- **Documentación:** Javadoc
